# React Practice Projects ⚛️

A collection of **React projects** ranging from **beginner to advanced** – perfect for learning and practicing React concepts step by step.

Each folder is a standalone mini-project that demonstrates specific features and best practices.

## 📚 Projects Included

| Concepts Covered                              |
|-----------------------------------------------|
| useState, basic events                        |
| Conditional rendering, lists & keys           |
| useState, arrays, carousel logic              |
| Controlled components, toggle state           |
| Filtering, categories                         |
| Dynamic tabs, content switching               |
| Custom hooks               |
| Forms                  |
| useRef                     |
| LocalStorage, CRUD operations                 |
| Responsive menu, useEffect cleanup            |
| Context API, compound components              |
| Advanced layout, submenus                     |
| Context API, reducers                         |
| Fetch API, async/await, React Router          |
| Redux, Redux Toolkit, RTK Query, etc.         |

## 🚀 How to Run Any Project

```bash
# Clone the repo
git clone https://github.com/MuhammadKhizar89/12-React-Projects-Basic-to-Advance-Concepts-.git

# Go into any project folder
cd React-Practice-Projects-/01-counter   # example

# Install dependencies
npm install

# Start the development server
npm start
